# hw07 肺炎X光片分类作业

## 目录结构
- figures/: 训练曲线与混淆矩阵图片
- train.ipynb: 完整训练代码
- requirements.txt: 依赖包列表
- report.md: 实验报告

## 运行方式
1.  下载数据集：https://www.kaggle.com/paultimothymooney/chest-xray-pneumonia
2.  解压后将`chest_xray`文件夹放在与代码同级目录
3.  安装依赖：`pip install -r requirements.txt`
4.  运行`train.ipynb`，完整执行所有单元格

## 测试集指标
- Accuracy: 0.92
- Precision: 0.91
- Recall: 0.96
- F1 Score: 0.93
